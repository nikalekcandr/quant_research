# btcvol v6.2 — что запускать до сдачи 1 ноября

**Всё одной командой** (окно с загрузкой Kalshi перед этим закрыть — она продолжится сама):

```powershell
cd C:\Users\Administrator\Downloads\btcvol_logger\btcvol_project
Expand-Archive -Force ..\btcvol_v6_2.zip .
powershell -ExecutionPolicy Bypass -File go.ps1
```

`go.ps1` по шагам: установка → тесты → площадки → глубина истории → задачи планировщика (логгер, прогнозы, ночное обновление, быстрый логгер) → вся история → свечи Kalshi за весь час → диапазоны → финальная сборка и отчёты. Повторный запуск пропускает сделанное. Лог — `logs\go.log`. Ниже — подробности, читать не обязательно.


Модели не менялись: `models.py`, `evaluate.py` и `measure/*` побайтно совпадают с версией 15 октября. `oos_report.py` проверяет это при каждом запуске.

В `build.py` одна задокументированная правка. До 18 марта 2026 Kalshi ставил страйки через $250–1000, и правило «каждый второй страйк через $200» оставляло от лесенки 2–3 точки. Теперь при таком шаге берётся каждый страйк. Для шага $100 (июль–октябрь, все новые и живые лесенки) выбор тот же, что был: таблицы v5 воспроизводятся до последнего знака.

## Что в пакете

**Данные и модели**

| Файл | Что делает |
|---|---|
| `backfill.py` | `--probe` ищет самую раннюю историю Kalshi и Polymarket. Без флага качает всё недостающее (сначала новые данные с 13.10, потом старое, от свежих месяцев к старым) и пересобирает. Дни января–марта, скачанные с 2–3 страйками, перекачивает сам |
| `daily_update.py` | ночью: новые данные всех источников → пересборка в соседних папках → подмена → оценка живых прогнозов → `oos_report`, `alpha_live`, `alpha_extra` |
| `oos_report.py` | одни и те же метрики на трёх выборках: **история** (1.01–12.10), **новые данные** (с 13.10) и **live**. Плюс спреды, сверка live с ночным пересчётом и проверка кода |

**Живой логгер — каждые 10 минут** (`live_once.py`, планировщик Windows, будит компьютер):

| Что пишет | Откуда |
|---|---|
| лесенки «выше K» | Polymarket (все открытые дни), Kalshi KXBTCD |
| **новое в v6.2:** опционы OKX и Bybit | вся цепочка BTC (улыбка), ещё две площадки для B3 |
| диапазоны | Kalshi KXBTC |
| **новое:** все остальные Bitcoin-рынки | Kalshi (`kalshi_other`: дневные, недельные, max/min, 15-минутные…), Polymarket (`pm_other`: Up or Down на час и 15 минут, диапазоны «price on», барьерные «what price will Bitcoin hit»…) |
| **новое:** опционы | Deribit (вся цепочка), Binance Options (`binance_options`) |
| цена | Binance |

**Живые прогнозы:** на час в HH:05, на сутки и 6 дней в 12:00 по Нью-Йорку. Все пишутся в цепочку SHA-256 `forecasts_live/ledger.csv`.

**Альфа на реальных стаканах — `alpha_live.py`.** Правила зафиксированы 28.10, до данных. По каждому — сделки, прибыль после комиссий, t-статистика и поправка Холма:
- **A1, A2** — безрисковые арбитражи: внутри лесенки (`bid(K2) > ask(K1)`) и «коробка» Kalshi «выше K» против суммы диапазонов;
- **B1** — Kalshi и Polymarket на одном расчёте (12:00 ET), последний час;
- **B2, B3** — Polymarket против цифровой цены с **улыбки** Deribit и Binance Options (не только ATM);
- **C1** — продажа дешёвых крыльев по реальному bid;
- **D1** — прочие рынки (диапазоны, барьеры, другие серии Kalshi) против улыбки Deribit;
- **E1** — запаздывание котировок за ценой BTC: мark-out через 30 и 60 секунд, по данным `fast_logger.py` (котировки каждые 10 секунд в последний час перед 12:00 по Нью-Йорку, запускается планировщиком сам).

**История — `alpha_extra.py`:**
- **X1** — комиссия Kalshi с округлением до цента. На истории +2,4¢ превращаются в +1,9¢ (t = 1,37) для одиночных ордеров.
- **X2** — растёт ли преимущество к расчёту: котировки за 55/40/25/10 минут.
- **X3** — арбитраж «коробки» KXBTCD против KXBTC поминутно.

**Прочее:** `discover_venues.py` — разовая проверка всех площадок с сырыми образцами ответов. `status.py` — здоровье логгера. Binance сам переключается на зеркало при 451.

## Шаг 2. Площадки и глубина истории (3 минуты)

```powershell
python discover_venues.py
python backfill.py --probe
```

Первая команда покажет, что отвечают Kalshi, Polymarket, Binance Options и Limitless, и сохранит образцы в `data\live\discovery\`. По ним я проверю разбор. Вторая найдёт самые ранние даты лесенок и запишет их в `data\manual\starts.json`.

## Шаг 3. Включить логгер, живые прогнозы и быстрый логгер

```powershell
powershell -ExecutionPolicy Bypass -File install_tasks.ps1
```

Скрипт создаёт три задачи:
- `btcvol-live` — каждые 5 минут;
- `btcvol-daily` — в 05:10;
- `btcvol-fast` — в 17:55 и 18:55; работает только в последний час перед 12:00 по Нью-Йорку.

Windows (один раз):
- **Электропитание → Дополнительные параметры → Сон → Разрешить таймеры пробуждения → Включить**;
- ноутбук на зарядке, закрытие крышки → «Действие не требуется».

Через 10 минут — `python status.py`.

## Шаг 4. Докачать всё и пересобрать

Пока Kalshi январь–июнь качается в другом окне:
```powershell
python backfill.py --no-kalshi
```

Когда Kalshi закончит, в том же окне поставь очередь на ночь:
```powershell
python backfill.py; python -m src.download.kalshi 2026-07-01 --minutes 60; python -m src.download.kalshi 2026-07-01 --series KXBTC --minutes 60; python daily_update.py --no-download
```
- `backfill.py` перекачает разреженные дни января–марта и докачает более ранние месяцы, если они есть.
- Следующие две загрузки — свечи за весь час для X2 и диапазоны для X3, по ~2–3 часа каждая.
- Последняя команда пересоберёт всё и посчитает все отчёты.

| Источник | Время |
|---|---|
| Polymarket, вся история | 20–40 мин |
| Deribit, сделки | 10–20 мин |
| Kalshi, январь–июнь | ~4 ч |
| Kalshi, разреженные дни января–марта заново | ~30 мин |
| Kalshi KXBTCD весь час, июль–октябрь | ~2–3 ч |
| Kalshi KXBTC весь час, июль–октябрь | ~2–3 ч |
| Сборка | 10–15 мин |

Прервалось — та же команда продолжит с места остановки. `403` от Kalshi — другая сеть (VPN, раздача с телефона).

## Шаг 5. Каждый день

- `python status.py` — логгер пишет, прогнозы kx1h без `late`, ночное обновление завершилось.

- Отчёты: `reports\oos_report.md`, `reports\alpha_live.md`, `reports\alpha_extra.md`. Если чат связан с компьютером, я забираю их сам.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `status.py`: «not writing!» | Компьютер спал при выключенных таймерах пробуждения, или задачи нет: `Get-ScheduledTask btcvol*` |
| Много `late` у kx1h | Компьютер просыпается позже HH:07. Держи его включённым |
| `another run is in progress` | Удали `data\.backfill.lock` или `data\.daily_update.lock` |
| `all Binance hosts failed` | Нет сети или заблокированы все хосты Binance. VPN |
| `binance_options` / `kalshi_other` / `pm_other` с ERROR в логе | Пришли `logs\live_*.log` или ничего не делай: я посмотрю сам. Остальное пишется дальше |
| Убрать задачи | `powershell -ExecutionPolicy Bypass -File uninstall_tasks.ps1` |
